### What is new in 1.1.0

- **Audiobookshelf SD Plugin**: Browse/search libraries, match existing SD EPUBs, queue offline progress, and run two-way EPUB CFI sync from Home -> Plugins and Reader Menu -> Sync Progress.
- **EEGO A4 & BOOX Picco**: Added `eego_a4` target, factory UID row, slim inset progress bar, and 500 ms idle, plus Picco `0xE0000` slot guards and `#4362` EPD improvements.
- **CrossInk & SDK**: Added 5-slot bottom modular status bar, File Transfer OPDS, CrossInk 2.0 touch/edge/tilt controls, and all-PSRAM wolfSSL + OPDS fixes in `freeink-sdk`.
- **Apps & Reader**: Synced CrossPlay `v1.15.1` Study paging/clock/`.lst` fixes, Notes edit label, Wikipedia install face/margins, OPDS 401 retry + `ClockFloor`, Show File Extensions, Recent opened-only filter, and `OptionPopup` scroll.
